# „Gdzie otworzyć?” v3 — mgła + model Huffa Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zamienić dynamiczną mapę heksagonów (v2) na przepływ „miejsce + promień → mgła” z modelem Huffa, czytelnymi nazwami warstw i szczegółami po kliknięciu.

**Architecture:** Nowy moduł `backend/app/analysis/surface.py` liczy wartości na regularnej siatce (EPSG:2180) w okręgu: Huff `E`, popyt `P`, zagęszczenie firm `K`. Endpoint `/api/surface` zwraca siatkę + top-5; `/api/point` daje liczby w okręgu zasięgu i komórki res 9. Frontend rysuje siatkę jako wygładzony obraz (`L.imageOverlay`) w skali log YlOrRd z przezroczystością.

**Tech Stack:** bez zmian (Python 3.13/uv, FastAPI, DuckDB, numpy, scipy cKDTree, pyproj, h3; Leaflet 1.9.4, h3-js 4.1.0).

**Spec:** [docs/superpowers/specs/2026-10-27-v3-mgla-huff-design.md](../specs/2026-10-27-v3-mgla-huff-design.md) — czytaj w całości (wzory, dosłowne teksty, kolory). Kontekst: [spec v2](../specs/2026-10-27-widok-dynamiczny-design.md), [raport ETL](../../raport-etl.md).

def test_decay_cutoff():
    v = decay(np.array([0.0, 1000.0, 4001.0]), 1000)
    assert v[0] == 1 and v[1] == pytest.approx(math.exp(-1)) and v[2] == 0

def test_huff_no_competitors():
    E = huff_expected(np.array([[0.0, 0.0]]), np.array([[1000.0, 0.0]]), np.array([100.0]), np.empty((0, 2)), 1000)
    f = math.exp(-1)

def test_huff_competitor_reduces():
    g = np.array([[0.0, 0.0]]); dem = np.array([[0.0, 0.0]]); w = np.array([100.0])

    shared = huff_expected(g, dem, w, np.array([[0.0, 0.0]]), 1000)[0]
